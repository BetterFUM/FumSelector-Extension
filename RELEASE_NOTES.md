# FumSelector Extension 1.5.2

The course-list time column again uses Pooya's original tooltip data. The
weekly timetable itself reads each calendar event's day and visible time so it
continues to render even when the portal collapses the event dimensions.

Selected courses now show how many students have chosen them. Courses above
capacity carry a compact red warning. The embedded portal frame is also sized
explicitly, preventing the blank calendar view.
